# Static assets

Docusaurus copies this directory to `/img/` in the built site.

| File | Size | Use |
| --- | --- | --- |
| `favicon.ico` | 16 / 32 / 48 | Browser tab icon (`rel="icon"`) |
| `favicon-16x16.png` | 16×16 | High-DPI / PNG fallback |
| `favicon-32x32.png` | 32×32 | High-DPI / PNG fallback |
| `apple-touch-icon.png` | 180×180 | iOS home screen |
| `logo.png` | 512×512 | Brand mark (available at `/img/logo.png`) |

Reference in markdown:

```
![ShellUI](/img/logo.png)
```
